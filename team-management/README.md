## Règles de base

- On ne pousse **jamais** directement sur `main`
- Chaque tâche = une **branche** + une **Pull Request**
- Toute PR doit être relue par **au moins 1 autre membre** avant d'être mergée
- On utilise le **GitHub Project** du repo pour suivre les tâches
